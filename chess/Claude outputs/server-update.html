Putting the new online games live

Build 2026-11-04.1-server-games-accounts. About 5 minutes. Nothing to set up in Cloudflare: the Worker keeps its name and address.

1 · Push to GitHub

  1. Run commit.bat as usual. It commits everything in the folder, including the changed server files and the new vendor/qrcode.js.
  2. Cloudflare rebuilds the Worker from the push by itself.

2 · Check the Worker built

  1. In the Cloudflare dashboard, open Workers & Pages, then etude-tables, then Deployments (or Builds).
  2. The newest build should say it succeeded. If it failed, open it, copy the last 20 or so lines of the log, and paste them to Claude.
  3. Open https://etude-tables.subjectification.workers.dev in a browser. It should say “Étude server. Nothing to see here.” (The old message said “table server”; if you still see that, the new build hasn’t gone live yet.)

3 · Make your account

  1. Open Étude on your phone and press Force reload (Settings in any game) if the version at the bottom of the home screen isn’t 2026-11-04.1-server-games-accounts.
  2. Tap the person icon at the top right of the home screen. Type your name and press Create.
  3. Save the key it shows: Copy key, and paste it into a password manager or a private note.
  4. To use the same account on another phone: on this one, Show key, and scan the QR code with the other phone’s camera. For your PC: Show key, Copy link, send the link to yourself, and open it on the PC.

4 · Notifications

  • Android (Chrome): in Your account, set When it’s your move to On and allow notifications. Send a test notification checks it; the test shows once Étude is off screen.
  • iPhone: first add Étude to the Home Screen (Safari, Share, Add to Home Screen) and open it from there. Then turn notifications on inside that copy. In a Safari tab the switch can’t work, and the app says so.

5 · Playing

  • Your friend makes an account the same way. Then add each other in Your account (search for the name, or type the code beside it), or skip that and send them an invite link from Play a game → Against a person → Online: opening it asks their name, starts the game and makes you friends.
  • A challenge appears on their home screen with Accept and Decline. Games under way are in Resume a game, with “your move” first.
  • Old table links stop working with this build, and games on them can’t be reopened. Their moves are still in Game history.

If something doesn’t work

In any game, Settings → Copy report, and paste the report to Claude along with what happened.

Usage stays on the free plan: each move, chat message or list update is one Durable Object request, against 100,000 a day.
