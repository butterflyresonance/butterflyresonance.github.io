Setting up the table server

About 10 minutes, once. Free. Nothing to install on your computer: Cloudflare builds the server from your GitHub repo.

1 · Put the new files on GitHub

  1. In your chess folder there is now a folder called server with three files: worker.js, wrangler.toml and package.json.
  2. Commit and push them to GitHub the way you usually push the app (the same commit can include the updated index.html).

2 · Make a Cloudflare account

  1. Go to dash.cloudflare.com/sign-up and sign up with your email. The free plan is all this needs. No card is required.
  2. Confirm your email address from the email they send.

3 · Create the Worker from your repo

  1. In the Cloudflare dashboard, open Workers & Pages (in the left menu, sometimes under Compute).
  2. Click Create, then choose Import a repository (it may say Connect to Git).
  3. Connect your GitHub account when asked, and pick the repository butterflyresonance.github.io.
  4. Fill in the settings:
    Project / Worker name: etude-tables  (must be exactly this — it matches the file)
    Build command: leave empty
    Deploy command: npx wrangler deploy  (usually filled in already)
    Root directory / Path: chess/server
  5. Click Create and deploy (or Deploy). The first build takes a minute or two.
  6. If Cloudflare asks you to choose a workers.dev subdomain, pick anything short — it becomes part of the address.

The screens change from time to time, so the button names may differ slightly. What matters is: import from Git, that repo, name etude-tables, path chess/server.

4 · Check it and send me the address

  1. When the build finishes, Cloudflare shows the Worker's address, ending in .workers.dev — for example https://etude-tables.yourname.workers.dev.
  2. Open that address in your browser. It should say “Étude table server. Nothing to see here.”
  3. Send me the address. I'll put it into the app, and from then on online games go through it.

If the build fails

Open the failed build in the dashboard, copy the last 20 or so lines of its log, and paste them to me.

Afterwards

  • Whenever you push to that repo, Cloudflare rebuilds the Worker automatically. That's harmless: if the server files haven't changed, nothing changes.
  • Usage is under the Worker's Metrics tab. A day of games should be a tiny fraction of the free 100,000 requests.
  • The server keeps nothing: no games, no accounts. It only passes messages between the two phones at a table, and only for pages on your site.
