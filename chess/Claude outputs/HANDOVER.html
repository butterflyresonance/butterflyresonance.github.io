How David likes changes made

  • Back up index.html into Claude outputs, bump VERSION (format YYYY-MM-DD.N-word), test, save to his folder, then confirm the md5 on his machine matches.
  • Test in a real browser (Playwright) before delivering, at phone size as well as laptop. Check layout visually, not just behaviour.
  • When he says "let me know before making changes", propose and wait.
  • Be concrete and direct; he dislikes flair and implied instructions. When he asks a question, answer it rather than starting work.
  • Naming: plain, specific words; never name something by reference to how it used to be (e.g. "Reconnecting", not "Reconnecting by itself"). Avoid Britishisms that read oddly ("Carry on" became "Games to resume"/"Resume a game"). Same feature, same name everywhere ("Best move", not sometimes "Hints").
  • Mode-specific controls appear only in the modes they belong to; shared settings (review toggles, appearance) are global and consistent.
  • One-off clean-ups of old saved data go in the Migrations section near the end of the script (remove after 2026-12-01).
  • Guides/documents as files: HTML, not Markdown.

Decisions already made (don't revisit without reason)

  • Online play (since 2026-11-04.1): every online game is kept on his Cloudflare Worker etude-tables.subjectification.workers.dev (server/worker.js), which is the record. Durable Objects: Directory (name/code search, the push signing key it makes itself, newest build seen), User per account (friends, requests, games list, push subscriptions, open WebSockets), Game per game (moves checked with chess.js, chat, takeback/rematch asks, time limit via alarms). One WebSocket per phone to its User while the app is open; moves carry their ply and the server replies with the game. Cloudflare builds it from GitHub on every push, deploy command npx wrangler deploy --config chess/server/wrangler.toml. No secrets to set.
  • Accounts: an Ed25519 key pair made in the browser; the id is the public key; the 32-byte private key ("your key": 52 base32 characters, or a #key= link/QR) never leaves the device. Login = signing etude:<id>:<time>. Names aren't unique; the 8-character code (XXXX-XXXX) is. Only online play needs an account; opening an invite link asks for a name. Joining via a game invite link makes you friends; so does opening someone's friend link (#add=<id>.<signature of "etude-friend:<id>">&n=<name>, permanent; kept in etude:addLink until an account exists); adding by search needs acceptance. Time limit per move is chosen per game (none, 1, 3, 7 days); running out loses.
  • Notifications: an in-app pop-up when a device has the app on screen, Web Push otherwise (the server decides from each socket's visibility). Toggle and test in Your account. iPhone needs the Home Screen app.
  • Home has the account (person) button top right; the version is in the home footer; the diagnostics panel is gone; Settings has Version, Force reload and Copy report. Test online locally with wrangler dev and localStorage['table:server'].
  • Leaving a game reloads the page on purpose (clean state). Screen changes otherwise fade out/in; no fade after a reload.
  • Every game on the device is its own saved "line" (table:lines); the Play buttons always start a new game; resuming only from Resume a game. Set-up positions are named when started.
  • Puzzle scoring: each hint costs a third of the whole puzzle (three hints = giving up); wrong tries add their severity on top, capped at giving up.
  • Eval bar only beside the board (the under-the-board option broke on iPhone and was removed). Review parts (eval bar, badges, their moves, explanations, best move) toggle independently.
  • "Engine plays" stays in online games (David's choice).
  • Analytics: not wanted.
  • Home: Puzzles, Play a game, Study (Famous games, Import a game, Analyse a position), and Resume a game when there is one.
  • Famous games: taken from PGN Mentor files (via the GitHub repo rozim/ChessData), each checked for legality, result, ending and key move; descriptions are our own words. Tal must stay represented (three games now), but no player collections.
  • Piece sets: several are CC BY-NC-SA — matters if donations are ever added.
